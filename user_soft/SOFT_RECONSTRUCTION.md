soft_v1_stable is a controlled target change: fit scales only on TRAIN metadata, store exact source-ID hash and specification, reuse for validation/test. Temporal scale is train max-min. Continuous scale is the norm of training feature-wise ranges (Euclidean for euclidean geometry); categorical scale1 and circular K/2 are geometry constants. A constant component uses1 with an explicit flag. No clipping or minibatch re-estimation is applied. log_Q uses masked log-softmax of -D/tau_metadata. P uses masked log-softmax of cosine logits; forbidden log probabilities are zeroed before multiplication. Empty candidate rows error by default; explicit skip requires at least one valid row. Nonfinite inputs, weights, scales and temperatures error.

Rat metadata mapping is a joint raw Euclidean vector (position,right,left) and local trial time, each weight0.5. This does not decompose direction categorically or normalize each behavioral coordinate separately. Such alternatives change the target and remain deferred. The rat linear track must not be mapped to the old synthetic eight-condition circular label distance.

Cross-trial relationships at compatible local time are intentional. Trial/session identity and temporal coordinate determine provenance and alignment, not a hidden same-trial eligibility mask. The loss is encoder independent; the official CEBRA offset10-model is instantiated unchanged by qualification/runner code. The recovered Transformer is a compatibility test, not an authorized architecture rewrite.

Stable version sanitizes the intermediate and detaches metadata. No previous scientific artifact is invalidated by this observation.
